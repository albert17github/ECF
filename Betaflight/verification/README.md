# BF ECF r4 验证范围

本修订检查源码清单、构建产物与发布包一致性，采用独立解压源码重建。实际结果以 `acceptance.json`（ArduCopter 为 `board-acceptance.json`）及发行附件中的 `final-source-zip-rebuild.json` 为准。

Betaflight 的 DMA 修复、PX4 的 DShot 计数修正分别提供主机回归与实机输出回归。INAV／ArduCopter 运行源码不变，重建镜像与上一修订逐字节一致；同一镜像既有实测记录通过哈希关联。测试仍保留原生解锁限制。

接口默认采用 ADC＋UART3；两组共享接口保存重启后生效，未选端高阻，外部接线互斥且限 3.3V。模拟参考为 11∶1、20mV/A、零偏 0；换用底板须标定。

输出波形仅声明实际测量的通道、协议和速率。幅值、过冲、电调返回、外部接收机／GPS／罗盘／CAN 互通、并发满载、逐板校准及飞行不因代码或波形检查自动视为通过。

灯语源码与上一修订一致。既有实物灯色记录与对应源码哈希保留关联；本修订新增检查范围单列，不将历史全量验收改写为本修订全量实测。
