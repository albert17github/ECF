# ECFH743 INAV target

STM32H743VIH6, 8 MHz HSE, ICM45686 on SPI1, BMP581 and MMC5983MA on I2C2, and SDMMC2 four-bit storage. VIN requires regulated 5 V. External signal levels are 3.3 V.

CH1–8 use PA0/PA1/PA2/PA3, PB1/PB0, and PD14/PD15. TIM2 serves CH1–4, TIM3 serves CH5–6, and TIM4 serves CH7–8. TIM1 remains reserved for IMU reference clocks. The default mixer uses CH1–4 with DShot300; CH5–8 are unassigned.

USB and UART1/3/4/5/6/7/8 are available. Factory UART1 uses CRSF/ELRS, UART5 uses MSP at 115200 baud, UART6 uses GPS at 115200 baud and UART7 uses native serial ESC telemetry. UART4 is unassigned because this baseline supports one GPS. `ecf_io_mode` explicitly selects 0=ADC/I2C4, 1=ADC/UART3 (factory), 2=UART8/I2C4 or 3=UART8/UART3. A selected UART can remain unassigned to a protocol. The selection takes effect on reboot, and inactive partner pins remain analog with no pulls. External circuits on each shared connector must be mutually exclusive. When changing back from UART8, explicitly enable the required analog sources.

`adc_vbat_channel`, `adc_current_channel`, `adc_rssi_channel` and `adc_airspeed_channel` select 0 for disabled, 1 for PC5 or 2 for PC4. Voltage/current default to channels 1/2; RSSI/airspeed default to disabled. Scaling is carrier-specific and needs calibration. UART8 masks all effective analog functions; forced ADC RSSI and pitot sources are also disabled when selecting that port. Saved routing remains available when returning to analog mode.

I2C3 uses PA8/PC9; I2C4 uses PD12/PD13. SPI4 uses PE2/PE5/PE6 with PE3 chip select and PE4 interrupt for a second ICM45686 selected by `gyro_to_use = 1`; the default sensor is index 0 on SPI1. PE9/PE13 clock outputs remain high impedance.

The DroneCAN subsystem is pinned to upstream commit `13ebed98e40c8990a6dd849eb8c809967976de40` and integrated into the 9.1.0 baseline. `dronecan_enabled` defaults to ON, CAN1, node 10 and 1000 kbps. Select CAN1 on PB9 TX/PB8 RX or CAN2 on PB6 TX/PB5 RX with `dronecan_device`; one controller is active at a time. The other pair remains analog with no pulls. Supported nominal rates are 125, 250, 500 and 1000 kbps, with an 80 MHz controller clock. External buses require a 3.3 V logic transceiver and suitable termination. Assign a unique node ID on each network.

Use `dronecan_loopback = OFF` for normal operation. Explicit internal loopback is for an unloaded bench and sets the `CANTEST` arming block. `can_info` reports the initialized controller, clock, hardware registers and queued/completed/received counters. `can_test <nonce>` sends a diagnostic NodeStatus through the real controller's TX/RX FIFOs and checks its standard DroneCAN decoding. The virtual diagnostic peer uses node 126 or 127 and does not represent a connected external device. The corresponding MSP diagnostic requires the correct MCU UID, the exact request length, internal loopback and a disarmed board.

DroneCAN GPS and battery data are selectable with `gps_provider = DRONECAN`, `vbat_meter_type = CAN` and `current_meter_type = CAN`. Factory GPS uses UBLOX on UART6 and voltage/current use ADC channels 1/2. Factory scaling is 11:1 voltage division, 20 mV/A and zero offset. CAN configuration changes take effect after save/reboot. The ECF configuration schema is 128, with the extended CAN parameter group at version 2.

Factory sensor selections are ICM45686, BMP581 and automatic compass detection. I2C3 probes external compasses before falling back to the onboard MMC5983MA on I2C2. The AUTO selection and default alignment remain stored across saves/reboots; only the onboard MMC5983MA receives the fixed CW0FLIP mounting compensation at runtime. Factory parameters do not contain per-board accelerometer or compass calibration. Calibration and arming interlocks remain active. Blackbox is disabled in the default feature set and `blackbox_arm_control` defaults to 0. The single RGB LED identifies INAV with three magenta startup flashes, then returns to arm-state and warning display; arming-disabled warnings are yellow.

For a stationary, unloaded bench, explicitly enable Blackbox and select `blackbox_arm_control = -1` to record raw, uncalibrated accelerometer and compass samples after gyro zeroing, barometer baseline calibration, and the first compass sample. This target-specific raw logging path does not set calibrated flags or enable arming. Set the control back to 0 to finish the native log, then restore the normal configuration. Configurator sensor-status polling inhibits this manual logging mode.

`sd_info` reports boot-lifetime file-write byte counters as `ECFSD requested`, `accepted`, and `refused`. Successful lossless recording requires the counter increments to match the downloaded native file and zero refused bytes, in addition to complete parser validation. Counters do not measure SD metadata traffic and wrap at 32 bits.
