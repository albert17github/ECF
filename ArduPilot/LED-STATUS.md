# ECFH743 状态灯

适用硬件为 PB7 驱动一颗 WS2812B-2020-V6 的 ECFH743。以下为 2026-10-27 接口默认配置修订的应用程序灯语；参数修改、LED 布局更改或地面站临时覆盖可以改变显示。

## 开机识别

Betaflight、INAV、PX4 的识别提示为三次短闪，目标亮／灭各 150ms，总长约 0.9 秒。BF／INAV 的实际边沿受原生 LED 更新节拍影响。ArduCopter 保留原生通知灯语，初始化状态为红／蓝交替；初始化前可能保持此前灯色。识别颜色只表示固件种类，不能作为初始化、传感器健康或解锁检查通过的凭据。

| 固件 | 开机识别颜色 |
| --- | --- |
| Betaflight | 青色（绿＋蓝）短闪三次 |
| INAV | 紫色（红＋蓝）短闪三次 |
| ArduCopter | 原生初始化红／蓝交替；运行状态按原生通知显示 |
| PX4 | 白色短闪三次 |

Betaflight／INAV 从首次状态灯传输开始计时，均不阻塞飞控循环，已解锁时跳过识别覆盖；ArduCopter 使用原生通知状态。PX4 在调度器启动前显示识别色，随后交给原生状态控制。

## 灯语的共同规则

BF／INAV 的禁止解锁警告统一为黄色双闪，与 ArduCopter 的黄色双闪表达相同方向的状态。红色、黄色或紫色提示必须结合当前固件含义判断。BF／INAV 的蓝色常亮表示已解锁；ArduCopter／PX4 的解锁常亮色还区分定位状态。因此不能跨固件仅凭某一种颜色判断可起飞。

## Betaflight

默认 LED0 为解锁状态叠加警告，亮度 10%。

| 运行显示 | 含义 |
| --- | --- |
| 绿色常亮 | 未解锁的基础色；不保证全部解锁检查通过 |
| 蓝色常亮 | 已解锁的基础色 |
| 黄色双闪 | 未解锁且存在禁止解锁条件；查看配置器的具体原因 |
| 红色双闪 | 电池状态不为正常；检查电池检测、采样配置与电压 |
| 黄色／蓝色交替 | 原生失控保护处于激活状态 |
| 紫色双闪 | 翻龟／翻转恢复功能激活 |
| 白色或所设蜂鸣提示色 | 原生可视蜂鸣提示；仅在无上述警告时显示 |

警告使用约 1.6 秒循环的四个时段，每个时段 0.4 秒；双闪为亮／灭／亮／灭，各约 0.1 秒。多项警告可在各自时段依次出现，未占用时段显示基础色。校准没有单独的默认 RGB 颜色，校准导致的解锁阻止归入黄色提示。

## INAV

默认 LED0 为解锁状态叠加警告，各色亮度限制为约 10%。

| 运行显示 | 含义 |
| --- | --- |
| 绿色常亮 | 未解锁的基础色；不保证全部解锁检查通过 |
| 蓝色常亮 | 已解锁的基础色 |
| 黄色双闪 | 未解锁且存在禁止解锁条件 |
| 红色双闪 | 电池状态不为正常；检查电池检测、采样配置与电压 |
| 黄色／蓝色交替 | 原生失控保护处于激活状态 |
| 蓝色双闪 | 原生硬件健康检查失败；查看各传感器及 GPS 状态 |

四个警告时段与 BF 相同，约每 1.6 秒循环。启用 GPS 但未接 GPS、未完成传感器校准、未连接接收机的台架环境可能同时出现禁止解锁和硬件健康提示；不应为消除灯光而关闭这些检查。校准没有单独的默认 RGB 颜色。

## ArduCopter

默认 `NTF_LED_TYPES=256`、`NTF_LED_LEN=1`、`NTF_LED_BRIGHT=1`，使用标准通知源；USB 连接时保持原生低亮度限制。

| 运行显示 | 含义 |
| --- | --- |
| 红色／蓝色快速交替 | 系统正在初始化 |
| 红／蓝／绿循环 | 保存微调、ESC 校准、罗盘校准或温度校准进行中 |
| 黄色双闪 | 未通过解锁前检查 |
| 蓝色慢闪 | 未解锁，GPS 检查或位置条件未满足 |
| 绿色慢闪 | 未解锁，GPS 三维定位与位置条件满足且相应检查通过 |
| 绿色快闪 | 未解锁，差分定位等级与相应位置、检查条件满足 |
| 绿色常亮 | 已解锁，GPS 三维定位且位置有效 |
| 蓝色常亮 | 已解锁，GPS 或位置条件未满足 |
| 黄色亮／灭交替 | 遥控、地面站或电池失控保护提示 |
| 黄色／红色交替 | EKF 状态异常 |
| 黄色／蓝色交替 | GPS glitch 状态 |
| 黄色／白色交替 | 原生进水检测告警（需要相应输入支持） |

慢闪约亮 0.5 秒、灭 0.5 秒；绿色快闪约 0.1 秒亮／灭；黄色双闪为亮 0.2 秒、灭 0.2 秒、亮 0.2 秒、灭 0.4 秒。失控保护双色或亮灭交替的半周期约 0.5 秒。初始化与校准提示优先于失控保护，失控保护优先于普通解锁／定位提示。

## PX4

开机识别后使用原生 Commander 和 LED 控制器。

| 运行显示 | 含义 |
| --- | --- |
| 红色快闪 | 尚未通过飞行前检查 |
| 紫色快闪 | 系统负载过高的提示 |
| 黄色快闪 | 原生手抛起飞状态已准备好 |
| 绿色呼吸 | 未解锁，飞行前检查通过且全局位置、返航点有效 |
| 蓝色呼吸 | 未解锁，飞行前检查通过，但全局位置或返航点无效 |
| 绿色常亮 | 已解锁，全局位置与返航点有效 |
| 蓝色常亮 | 已解锁，全局位置或返航点无效 |
| 紫色呼吸／常亮 | 在普通待机／解锁显示路径中发生失控保护；呼吸表示未解锁，常亮表示已解锁 |
| 黄色呼吸／常亮 | 同一显示路径中的电池低电量警告 |
| 红色呼吸／常亮 | 同一显示路径中的电池严重低电量警告 |
| 白色快闪 | 相应原生校准步骤等待姿态确认等临时提示；以地面站校准页面为准 |

快闪约亮 0.1 秒、灭 0.1 秒；呼吸周期约 1.6 秒。过载、手抛准备、解锁和飞行前检查有原生优先顺序；紫色失控、低电量和定位色只在普通状态显示分支中选择。临时高优先级提示可覆盖普通状态。

## 使用边界

熄灭可能由 LED 功能禁用、低亮度、启动／刷写阶段或供电状态造成，不能单凭熄灭判定断电。灯光用于快速识别，故障原因和是否允许解锁应以原生配置器／地面站及检查结果为准。开机颜色和状态灯测试不得通过解锁或运行电机来确认。
